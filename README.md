# NEXORA — IT + AI Solutions Portfolio

A premium, cinematic Next.js portfolio starter for an IT + AI solutions company.

The visual direction is inspired by the supplied reference: dark editorial UI, oversized typography, warm metallic accent, atmospheric gradients, minimal navigation, and an immersive hero composition.

## Stack

- Next.js 15
- React 19
- TypeScript
- CSS Modules / global CSS
- App Router
- No UI framework required

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Production

```bash
npm run build
npm start
```

## Customize

The temporary brand name is **NEXORA**. Replace it in:

- `app/page.tsx`
- `app/layout.tsx`
- `app/globals.css`

Update the contact email in `.env.local`:

```env
NEXT_PUBLIC_CONTACT_EMAIL=hello@yourcompany.com
```

The site is intentionally dependency-light so it can be pushed directly to GitHub and deployed to Vercel, Hostinger Node hosting, AWS, or another Next.js-compatible platform.
